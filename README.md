# 🧠 Eback - Exercício de Bootstrap Avançado

Este projeto é parte do curso **MundoDev** e tem como objetivo aplicar conceitos avançados do framework [Bootstrap](https://getbootstrap.com/) para criar uma landing page moderna e responsiva voltada ao público desenvolvedor.

## 🚀 Funcionalidades

- Banner com título e descrição
- Carrossel de anúncios
- Cards de cursos com botão "Ver mais"
- Formulário de inscrição com validação
- Rodapé com colunas organizadas e links úteis

## 🛠 Tecnologias Utilizadas

- HTML5
- CSS3
- Bootstrap 5
- Font Awesome (opcional)
- Responsividade mobile-first

## 📸 Layout

A página apresenta:

- Um banner principal com chamada para ação
- Cards de cursos com data e hora de postagem
- Formulário de inscrição com campos de nome, e-mail e aceite dos termos
